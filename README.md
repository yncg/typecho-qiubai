# 秋白博客 · Typecho 深度定制版

基于 Typecho 1.3.0 改造的个人博客程序。

本仓库是**未安装状态的完整站点包**，不含 `config.inc.php`，拿到后直接访问 `/install.php` 走安装流程即可。

## 改动清单

### 一、站点与主题

- 站点离线化，不再依赖任何外部资源
- default 主题整体改造
- 后台静态资源的版本号改为跟随文件修改时间，解决手机端看不到新样式的问题
- 后台页脚只保留版本号，去掉上方那一行图标

### 二、文章配图与编辑器

- 新增图库写入接口
- 编辑器新增 T、Red、Pur 三个按钮
- 新增直接上传本地图片，并自动压缩到 50KB 以下用 Base64 存到数据库，正文只保留一行引用标记
- 新建文章时自动插入当前详细日期，并把光标落到下一行
- 移除未来日期文章不能打开的限制

### 三、评论

- 已有的评论换到按钮下边
- 移除要填写 email 和 url
- 取消昵称必填的限制

### 四、备份

- 备份页面整体重写，写明两种备份方式各自备份什么、有什么不同、要注意什么
- 把 Adminer 数据库管理工具并入站点，备份页新增入口按钮
- 修复手机端备份文件无法下载的问题
- 登录逻辑调整后，整库导出的内容包括全部设置与全部 Base64 配图

### 五、登录

- 同一个账号在多台设备上登录，不再互相挤下线
- 登录状态改为长期有效

### 六、其他

- 新增一份未安装状态的完整站点包

## 环境要求

- PHP 7.4.0 或更高
- 数据库：MySQL / MariaDB 5.5.3 以上，或 SQLite 3.7.11 以上，或 PostgreSQL 9.1 以上
