## 改动清单

1、问题：手机点击备份按钮无法下载备份文件，页面上能看到文件大小但无法保存，电脑上可以正常下载。

修复：后台操作令牌的计算依赖 Referer 请求头，手机浏览器发送该请求时不携带 Referer，令牌校验不通过后跳转登录页，下载随之中断。令牌改为绑定目标地址，即路径加查询串；导出动作写入表单 action 地址，支持以 GET 方式重试；原基于 Referer 的校验保留作为兜底。

2、问题：手机后台右上角的「账户名」「登出」「网站」三个入口不显示。

修复：三个入口原先位于工具栏内部，手机上不可见。改为移入移动端导航区并常驻显示；左侧保留「菜单」按钮用于展开原有侧边菜单，右侧固定放这三个链接。三个链接使用 display: contents 平铺进顶栏，并配置不支持该属性时的降级排列，同时补齐分隔竖线。

3、问题：文章发布日期设置为未来时间后，该文章无法打开。

修复：文章查询中存在一条时间过滤条件 created < 当前时间，未来日期的文章被排除。删除该过滤条件。

4、问题：「下一篇」链接的查询中带有一条时间上限条件，要求下一篇的发布日期在当前文章之后且早于当前时间。未来日期的文章因此无法通过「下一篇」链接被跳转到。

修复：删除该时间上限条件，只保留「发布日期在当前文章之后」这一条判断。

5、问题：编辑器工具栏缺少插入时间、插入彩色文字的快捷按钮。

修复：在工具栏的「图片」按钮右侧添加三个按钮，顺序为「图片 → T → Red → Pur」。三个按钮的用途如下：  
　　T：插入当前时间，格式为「2026年10月10日18:26:07」。  
　　Red：把选中的文字包成红色字体。  
　　Pur：把选中的文字包成紫色字体。  
三个按钮分别配了独立样式：T 为灰色，Red 为 #D9534F，Pur 为 #8A4FBD。

6、问题：上传图片的体积偏大。

修复：上传图片时自动压缩，压缩后的体积控制在 50KB 以下。

7、问题：写文章时需要手动敲入日期，插入当前时间不方便。

修复：增加「插入当前时间」按钮，一键插入当前详细日期。另外在新建文章时，若正文为空，自动在开头插入当前详细日期，并把光标定位到该日期所在行的下一行。

8、问题：以前用数据库备份、或者用程序自带的备份，都无法备份文章里的图片。图片以文件形式存放在服务器上，迁移和备份时容易丢失。

修复：文章配图改为 Base64 保存，图片直接存进数据库。新增图片仓储模块，图片以 Base64 文本形式写入数据库 images 表，正文中只保留一行引用标记，格式为 \!\[名称\]\[imgXXXX]；渲染文章时按标记取回图片数据并替换为 img 标签。编辑器增加本地图片上传入口，选择图片后自动压缩再入库。

9、问题：程序自带的备份页只有简单的提示文字，未说明会备份哪些数据，也未说明与数据库备份的区别。

修复：备份页整体重写，改为两大块结构。第一大块为程序自带备份，写明它只备份 6 张内容表（contents 文章与独立页面、comments 评论、metas 分类标签、relationships 文章与分类关联、users 用户、fields 自定义字段），不备份任何设置，也不备份 Base64 配图。第二大块为 Adminer 数据库备份，写明它备份全部 8 张表，包含表结构、索引、全部设置、Base64 配图、插件启用清单与站点密钥，并附操作步骤。下方增加逐项对比表。注意事项按四档颜色标注：红色为危险项，橙色为提醒项，蓝色为信息项，绿色为结论项。原提示文字全部移除。

10、问题：需要确认 Base64 图片是否会保存到数据库里。

修复：这种 Base64 的图片会保存到数据库的 images 表里。

11、问题：数据库管理工具需在站点之外单独部署，备份页无法直接进入。

修复：将 Adminer 6.1.1 官方单文件版放入站点根目录 adminer.php，备份页第二大块增加跳转按钮。访问校验采用最小初始化，只读取站点配置与设置 Cookie 前缀，不开启 session，避免与 Adminer 自身的会话设置冲突；仅已登录的管理员可进入，未登录时跳转登录页。

12、问题：同一账号在另一处登录后，先前登录的位置立即失效。

修复：登录时每次都重新生成 authCode 并覆盖数据库，而登录校验是使用浏览器 Cookie 中的 authCode 与数据库中的值比对，因此新设备登录后旧设备的凭据立即失效。修改为仅在该账号尚无 authCode 时生成，已存在则原样沿用。登录 Cookie 的有效期由随浏览器关闭失效改为长期保持，取「调用方指定时长」与「365 天」中的较大者。恢复备份后的重新登录同步使用相同有效期。

13、问题：评论区域的使用不便，评论表单位置靠后，且发表评论时必须填写邮箱、网址和昵称。

修复：将评论表单移到已有评论列表之前；移除邮箱与网址两个输入框；昵称改为可不填，留空时自动随机取名。

14、问题：站点依赖外部资源，无法离线运行。

修复：将外部资源本地化，站点不再引用外部资源。
